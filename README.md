# zmohajeri.github.io

Personal writing site, built with Jekyll and hosted on GitHub Pages.

## Adding a new post

English posts go in `en/_posts/`, Persian posts in `fa/_posts/`. Create a file named `YYYY-MM-DD-short-title.md`:

```
---
layout: post
title: "Post title"
date: 2026-11-13 10:00:00 -0500
cover: ""       # optional image URL
excerpt: "One or two sentences shown on the home page."
---

Your text here, in Markdown.
```

Commit it and GitHub Pages republishes the site in a minute or two.
